# CRUD de videojuegos en Java

Programa de consola para registrar videojuegos. La información se guarda mientras el programa está abierto.

## Opciones del menú

1. Agregar un videojuego.
2. Modificar sus datos.
3. Eliminarlo de la lista.
4. Mostrar los videojuegos registrados.
5. Salir.

Cada videojuego tiene nombre, plataforma y género. El programa utiliza List con ArrayList y captura la información con Scanner.

## Archivos

- Main.java: menú y operaciones del programa.
- Videojuego.java: clase con los atributos del videojuego.

## Cómo ejecutarlo

Abre una terminal en esta carpeta y ejecuta:

    javac Main.java Videojuego.java
    java Main
